Level Up - Android App

Level up App es una aplicacion nativa de android.
El proyecto principal es una tienda virtual con productos relacionados con videjuegos, perifericos y juegos de mesa.

En este proyecto se demuestra el dominio de las siguientes librerias y herramientas:

**Lenguaje:** KOTLIN
**Interfaz de Usuario:** JETPACK COMPOSE
**Networking:** RETROFIT 2
**Navegacion:** JETPACK NAVIGATION COMPOSE
**Arquitectura:** MVVM (Model-View-ViewModel)

Funcionalidades

**Consumo de API**
**Listas Dinamicas**
**Navegacion Fluida**
